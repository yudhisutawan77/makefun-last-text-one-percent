The funniest final text a dying phone sends at one percent battery — in the
voice of the phone itself. One line, under 200 characters, for the
[make.fun bounty](https://make.fun/bounty/u-azazex-last-text-at-one-percent-ba9fc876).

## The entry

> I'm at 1%. Before I go: I deleted your 6am alarm. Sleep in. You're welcome.

75 characters. The phone spends its last percent on petty revenge: it deletes
the owner's 6am alarm on the way out — a specific, unexpected turn, in the
phone's own voice from first word to last.

## Run

```sh
ENTRY_OUT=/output python3 main.py
```

`ENTRY_OUT` may be a file path or a directory; a directory gets
`entry.txt` inside it. The program writes the entry text exactly, with no
trailing newline.
